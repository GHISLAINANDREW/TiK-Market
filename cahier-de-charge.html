1. Présentation du projet

1.1 Contexte

Dschang Market est une plateforme de commerce en ligne destinée aux habitants et commerçants de Dschang (Ouest-Cameroun) et ses environs. L'objectif est de faciliter les échanges commerciaux locaux en proposant une solution moderne, accessible depuis le web et les appareils Android.

1.2 Objectifs

  • Faciliter l'achat local — permettre aux habitants d'acheter des produits auprès des commerçants locaux
  • Digitaliser les commerces — offrir aux vendeurs une vitrine en ligne
  • Paiements Mobile Money — intégrer Orange Money et MTN Mobile Money
  • Multi-plateforme — accessible depuis le web et les appareils Android

3.4 Flux des données

  1. Client (Web/Android) émet une requête HTTP(S) vers https://dschang-market.onrender.com
  2. API PHP (Render) reçoit la requête, valide l'authentification (JWT Bearer)
  3. Base Aiven (MySQL 8.0) exécute la requête SQL
  4. Réponse JSON renvoyée au client
  5. Les images sont stockées sur Cloudinary et servies via CDN
📌 Toutes les réponses API utilisent le format JSON. Authentification par token JWT (Bearer).

6. Cycle de vie de l'APK Android

6.1 De la source à l'APK

  1. Écriture du code Kotlin/Compose dans composeApp/src/commonMain/
  2. Compilation Gradle avec la tâche :composeApp:assembleDebug
  3. Génération de l'APK dans composeApp/build/outputs/apk/debug/composeApp-debug.apk
  4. Signature (debug signé automatiquement par le SDK Android)
  5. Installation manuelle sur l'appareil Android

9.1 Connexion à la base de données (database.php)

<?php function getDB() { $host = 'mysql-32d32cc7-tik-market.k.aivencloud.com'; $port = 10180; $db = 'defaultdb'; $user = 'avnadmin'; $pass = 'AVNS_***'; // à remplacer par la variable d'env DB_PASS try { // Tentative sans SSL (fonctionne sur Render) $pdo = new PDO( "mysql:host=$host;port=$port;dbname=$db;charset=utf8mb4", $user, $pass, [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION] ); return $pdo; } catch (PDOException $e) { // Fallback SSL $pdo = new PDO( "mysql:host=$host;port=$port;dbname=$db;charset=utf8mb4", $user, $pass, [PDO::MYSQL_ATTR_SSL_CA => true, PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION] ); return $pdo; } }

10. Difficultés rencontrées

10.1 🔴 Mode ANSI_QUOTES de MySQL (Aiven)

ProblèmeMySQL d'Aiven fonctionne en mode ANSI_QUOTES : les guillemets doubles sont des identifiants SQL, pas des chaînes
ImpactToutes les requêtes SQL avec "active", "admin", etc. échouaient
SolutionRemplacer systématiquement tous les guillemets doubles par des guillemets simples dans les requêtes SQL
Fichiers touchésproducts.php, shops.php, payments.php, register.php, fix_admin_role.php

10.2 🔴 SSL Aiven non fonctionnel sur Render

ProblèmeLa connexion SSL à Aiven via PDO échouait sur Render PHP 8.2.32
ImpactL'API ne pouvait pas se connecter à la base de données
SolutionFallback non-SSL dans database.php : d'abord tentative sans SSL, si échec tentative SSL

10.3 🔴 Import map dupliquée (Web WasmJS)

ProblèmeLe fichier index.html généré contenait deux objets JSON dans le même <script type="importmap">
ImpactLe navigateur ne pouvait pas parser l'import map, le chargement du module échouait
SolutionSuppression du doublon dans index.html

10.4 🔴 Chemin erroné de js-joda dans l'import map

ProblèmeL'import map pointait vers ./node_modules/@js-joda/core/dist/js-joda.esm.js mais le dossier dist/ n'existe pas
ImpactLe module js-joda était introuvable (404), l'application ne se chargeait pas
SolutionCopie de js-joda.esm.js à la racine et mise à jour du chemin dans l'import map

10.5 🔴 Rewrite Vercel trop large

ProblèmeLa règle /(.*) dans vercel.json attrapait tous les chemins, y compris node_modules/...
ImpactLes fichiers JS dans node_modules étaient servis comme index.html (SPA catch-all)
SolutionRemplacé par /([^.]*) qui ne matche que les routes sans extension de fichier

10.6 🔴 Vercel ignore node_modules/ lors du déploiement

ProblèmeVercel n'uploadait pas le dossier node_modules/ (exclu par défaut)
ImpactLe fichier js-joda.esm.js n'était pas disponible sur le déploiement
SolutionCopie du fichier à la racine du projet (hors node_modules)

10.7 🔴 Gitignore empêchant le tracking de dist-prod/

ProblèmeLe pattern composeApp/build/ dans .gitignore empêchait le tracking des fichiers de dist-prod/ car le dossier parent était exclu
ImpactLes fichiers pré-buildés ne pouvaient pas être commités pour l'auto-déploiement
SolutionRestructuration du .gitignore pour exclure les dossiers de build un par un plutôt que le dossier parent

10.8 🟡 PowerShell non fonctionnel

ProblèmePowerShell sur Windows ne reconnaissait plus les cmdlets de base (New-Item, Select-String, Start-Sleep, etc.)
ImpactImpossible d'utiliser des commandes PowerShell classiques
SolutionUtilisation systématique de cmd.exe /c pour les commandes shell, et java -jar gradlew au lieu de ./gradlew

10.9 🟡 Domaine gratuit .cf non disponible

ProblèmeLes domaines .cf, .ga, .ml, .gq ne sont plus gratuits
ImpactPas de nom de domaine personnalisé pour le site
Solution actuelleUtilisation de l'URL Vercel gratuite : dschang-market.vercel.app
Alternative payanteAchat d'un domaine .com pour ~2-3€/an

10.10 🟡 Page.printToPDF non disponible dans l'Electron OpenWork

ProblèmeLa commande CDP Page.printToPDF n'est pas exposée par l'application OpenWork
ImpactImpossible de générer des PDF automatiquement depuis l'outil
SolutionGénération HTML avec bouton d'impression → l'utilisateur utilise Ctrl+P (navigateur) pour sauvegarder en PDF

10.11 🟡 npm install lent / timeout

ProblèmeLes commandes npm install échouent ou timeout sur cet environnement
ImpactImpossible d'installer des dépendances Node.js (puppeteer, pdfkit, etc.)
SolutionUtilisation de scripts en Node.js natif (sans dépendances externes) ou utilisation du browser intégré
